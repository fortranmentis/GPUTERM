GPU 서버를 위해 만든 SSH·SFTP 클라이언트

GpuTerm은 터미널, 드래그 앤 드롭 파일 브라우저, 원격 호스트의 CPU·메모리·디스크·GPU 실시간 모니터링을 하나의 네이티브 창에 담았습니다. SSH 클라이언트, SFTP 도구, watch nvidia-smi를 따로 띄울 필요가 없습니다.

Windows .exe macOS Apple Silicon .dmg Linux .deb Linux AppImage

최신 버전: beta · GitHub 소스

GPU 서버에 필요한 모든 것을 한 곳에

한 번 연결하면 됩니다. 모니터링은 별도 SSH 채널로 동작해 셸을 막지 않고, 기본 지표는 서버에 에이전트나 root 권한 없이 수집합니다.

🖥️SSH 터미널

xterm.js와 Rust ssh2 기반의 완전한 PTY 터미널. 화면 분할, 검색, tmux 세션, ProxyJump, 포트 포워딩, keyboard-interactive·OTP 로그인, ~/.ssh/config 가져오기를 지원합니다.

📊실시간 GPU 모니터링

모든 GPU(NVIDIA, AMD, Intel, Apple Silicon)의 사용률, VRAM, 온도, 전력과 CPU, 메모리, 디스크, 접속 사용자를 기록 그래프와 임계값 알림과 함께 보여 줍니다.

📁SFTP 브라우저

드래그 앤 드롭 업로드·다운로드, 로컬/원격 두 창 보기, 진행률과 취소, 이름 변경, 삭제, 새 폴더.

🧠프로세스와 컨테이너

어떤 프로세스가 어느 GPU를 쓰는지, CPU·메모리 상위 프로세스, Docker/Podman 컨테이너와 Kubernetes 파드, PID를 다시 확인하는 안전한 "프로세스 종료".

🤖LLM 런타임 모니터링

Ollama, vLLM, SGLang, TGI, llama.cpp, Triton, OpenAI 호환 서버의 모델, KV 캐시, 대기열, 초당 토큰, 지연 시간을 직접 또는 SSH 터널로 확인합니다.

🔐기본부터 안전하게

Argon2id + AES-256-GCM 금고에 자격 증명 저장, 선택형 Touch ID·Windows Hello 잠금 해제, 호스트 키 확인, 자동으로 등록·검증하는 GpuTerm 관리 SSH 키.

AI 도우미가 GPU 서버를 보게 하세요

GpuTerm에는 MCP 서버가 들어 있습니다. 켜면 Claude Code, Claude Desktop, Codex, Cursor가 연결된 호스트에 대해 질문하고 답할 수 있습니다.

  • "GPU 비어 있는 서버가 어디야?" — 실시간 텔레메트리, 여러 호스트의 빈 GPU, 최근 1시간 기록, GPU 프로세스, 컨테이너, LLM 런타임.
  • 동작은 승인할 때만 — 명령 실행, 파일 읽기, 프로세스 종료는 매번 GpuTerm에 확인 창이 뜨고, 기본값은 거부입니다.
  • 로컬 전용, 기록 남김 — 루프백과 실행마다 새로 만드는 토큰, 호스트별 숨기기, 신뢰할 수 없는 출력 표시, 감사 로그.
$ claude mcp add --scope user gputerm -- \
    "/Applications/GpuTerm.app/Contents/MacOS/gputerm" --mcp-stdio

자주 묻는 질문

서버에 무언가를 설치하나요?

아닙니다. 기본 지표는 에이전트나 root 권한 없이 SSH로 nvidia-smi, /proc, sysctl, PowerShell CIM 같은 표준 명령을 한 번씩 실행해 가져옵니다.

어떤 GPU와 서버 OS를 지원하나요?

Linux, macOS, Windows 호스트의 NVIDIA(nvidia-smi), AMD(amd-smi·rocm-smi), Intel, Apple Silicon GPU를 지원합니다. 표시되는 항목은 호스트의 도구와 드라이버에 따라 다릅니다.

무료인가요?

PolyForm Noncommercial 1.0.0 라이선스로 개인·비상업적 사용은 무료입니다. 상업적 사용은 관리자에게 별도 라이선스를 받아야 합니다.

Termius나 MobaXterm과 무엇이 다른가요?

GpuTerm은 GPU 서버를 중심으로 만들었습니다. GPU별 텔레메트리와 기록, GPU 프로세스·컨테이너 보기, LLM 런타임 모니터링, AI 도우미용 MCP 서버가 터미널·SFTP와 함께 기본으로 들어 있습니다.
